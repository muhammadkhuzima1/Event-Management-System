
# Nowshera Events Co. – Event Management System

A full-stack event management website where attendees can discover and register for events, while administrators manage events and attendee registrations.

## Features

- Attendee signup and login
- Browse published events
- Event registration and cancellation
- Real-time capacity and available seat tracking
- Duplicate registration prevention
- Admin event management
- Admin attendee list and search
- Secure role-based access
- Supabase Row Level Security (RLS)

## Tech Stack

- React.js
- TypeScript
- Vite
- Supabase
- PostgreSQL
- Supabase Authentication
- Row Level Security (RLS)

## Tools

- Google AI Studio
- Supabase Dashboard
- Supabase SQL Editor
- GitHub
